KETCHUP AR LAB / PROJECT 01

Project ONEIROS ὄνειρος — dream

Pronunciation guide: OH-neh-ross

BUILD THE SUIT.LAUNCH THE HUD.

A dream worth building, one experiment at a time.

An independent, long-term personal engineering experiment exploring whether 3D-printed armor, AR glasses, a browser HUD, and modular tools can become one safe, honest wearable system. There is no fixed timeline and no guaranteed final result.

Launch Recon Scanner v0.7 ↗ Inspect the system

Recon Scanner is the existing browser-tested software milestone. It is simulated software, not a camera, radar, or integrated suit.
