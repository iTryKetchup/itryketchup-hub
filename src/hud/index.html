Ketchup HUD v0.6 · Live Activity Bars

Live clock, sensor-cycle countdown, and measured browser FPS. Compass, radar contact, scanner coordinates, and LINK activity are SIMULATED.

Safety: Experimental visual display only. No real object detection and not navigation guidance. Do not view while crossing roads or whenever situational awareness is needed. Configure before moving; the HUD does not require constant interaction.

Keyboard: N sensor · S settings · H hide · C color · M layout · P pause · B blank · F fullscreen · Escape exits fullscreen.

Install on iPad: in Chrome, use Share → Add to Home Screen. Safari's Share menu is supported as an alternative.

Pixel shifting and automatic black breaks are display-care options, not guaranteed burn-in prevention.
